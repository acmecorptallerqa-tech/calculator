                            ↓ depends on ↓

│  APPLICATION (Use Cases)             src/application/           │

│  → Orchestrates domain objects                                  │
└─────────────────────────────────────────────────────────────────┘
                            ↓ depends on ↓
┌─────────────────────────────────────────────────────────────────┐
│  DOMAIN (Business Logic)             src/domain/                │
│  Entities, Value Objects, Services, Repository Interfaces       │
│  → Pure business logic, ZERO dependencies                       │
└─────────────────────────────────────────────────────────────────┘
                            ↑ implements ↑
┌─────────────────────────────────────────────────────────────────┐
│  INFRASTRUCTURE (External I/O)       src/infrastructure/        │
│  Repositories, APIs, Database, localStorage                     │
│  → Implements interfaces from domain/application                │
└─────────────────────────────────────────────────────────────────┘

RULE: Dependencies ONLY point inward → Domain knows nothing!

================================================================================
                     DEPENDENCY INJECTION
================================================================================

Application initialization flow (src/interfaces/web/index.js):

1. Infrastructure Layer
   └── new LocalStorageCalculationRepository()

2. Domain Layer
   └── new CalculatorService()

3. Application Layer (inject domain dependencies)
   ├── new PerformCalculation(repository, calculatorService)
   ├── new GetCalculationHistory(repository)
   └── new ClearCalculationHistory(repository)

4. Interface Layer (inject use cases)
   └── new CalculatorController(performCalc, getHistory, clearHistory)

5. UI Layer (inject controller)
   └── new UIManager(controller)

================================================================================
                        DATA FLOW EXAMPLE
================================================================================

User Action: Clicks "5 + 3 ="

1. UIManager.handleEquals()
   ↓
2. CalculatorController.calculate("5", "+", "3")
   ↓
3. PerformCalculation.execute(PerformCalculationInputDTO)
   ↓
4. CalculatorService.calculate(5, Operator.ADD, 3)
   → Returns: 8
   ↓
5. new Calculation(5, ADD, 3, 8, timestamp)
   ↓
6. LocalStorageRepository.save(calculation)
   → Saves to browser localStorage
   ↓
7. Return CalculationResultDTO(result: 8, expression: "5 + 3 = 8")
   ↓
8. Controller formats response
   ↓
9. UIManager updates display: "8"
   ↓
10. UIManager refreshes history panel

================================================================================
                       BUSINESS RULES
================================================================================

🧠 Enforced in Domain Layer:

1. OPERATOR VALIDATION
   • Only valid operators: ADD, SUBTRACT, MULTIPLY, DIVIDE
   • Operators are type-safe (Operator value object)

2. DIVISION BY ZERO
   • Cannot divide any number by zero
   • Throws descriptive error

3. CALCULATION IMMUTABILITY
   • Calculations cannot be modified after creation
   • All properties are frozen

4. NUMBER VALIDATION
   • Only valid numeric inputs accepted
   • Handles decimal numbers correctly
   • Prevents NaN and Infinity

5. CALCULATION INTEGRITY
   • Each calculation has timestamp
   • Result must match actual calculation
   • Operands and result are validated

================================================================================
                      ADDING NEW FEATURES
================================================================================

📝 STEP-BY-STEP PROCESS:

1. IDENTIFY THE LAYER
   • Business rule?          → domain/
   • New use case?           → application/use-cases/
   • External service?       → infrastructure/
   • UI control?             → interfaces/web/

2. START WITH DOMAIN (if needed)
   • Create entity/value object/service
   • Write business logic
   • Add validation rules

3. CREATE USE CASE (application/)
   • Define input/output DTOs
   • Create use case class with execute() method
   • Orchestrate domain objects

4. IMPLEMENT INFRASTRUCTURE (if needed)
   • Implement repository interface
   • Add external service adapter
   • Handle serialization/deserialization

5. ADD INTERFACE (interfaces/)
   • Create controller method
   • Add UI controls
   • Wire up event handlers

6. UPDATE DEPENDENCY INJECTION
   • Add to DIContainer in src/interfaces/web/index.js

7. WRITE TESTS
   • Add test files in tests/ (mirror src/ structure)
   • Test each layer independently
